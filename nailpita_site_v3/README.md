# ネイルピタ お悩み別ランキングページ(v3)

40代・50代向け、ネイルのお悩み別に楽天の商品をランキング形式で紹介するサイトです。

## 今回の変更点(v3)

1. **お悩みカテゴリを13個に拡張**
   縦筋・波打ち凸凹・そり爪・二枚爪・薄い爪・ささくれ・深爪・噛み爪・巻き爪・横筋・手のしわ・手の乾燥・手荒れ
2. **「厳選静的データ + API」のハイブリッド方式に変更**
   事前にリサーチ済みの商品(アフィリエイトリンク確定済み)を `rakuten_sync.js` 内の `CURATED_PRODUCTS` に直接書き込みました。
   - これにより、楽天APIが落ちていても必ず各カテゴリ3点は表示されます(安全な土台)。
   - API自体は残してあるので、動いているときは画像や価格・レビューを自動で最新化します。
   - さらに各カテゴリ合計5点になるまで、キーワード検索で商品を自動的に補充します。
3. **スマホでの商品画像の見やすさを改善**
   - 画面幅560px以下では1列表示にして、画像をカードの横に大きく配置
   - 画面幅380px以下ではさらに画像を上段に大きく配置(縦積みレイアウト)

## ファイル構成(3ファイル + ワークフロー1つ)

```
index.html                         ← ページ本体(HTML+CSS)
script.js                          ← products.json を読み込んで表示するスクリプト
rakuten_sync.js                    ← 楽天の商品データを取得してproducts.jsonを作るバッチ
products.json                      ← 商品データ(rakuten_sync.jsが自動更新/初期は空)
.github/workflows/rakuten-sync.yaml ← 上記バッチを定期実行するGitHub Actions設定
```

## セットアップ手順(GitHub Secretsの登録は不要です)

楽天の認証情報(アプリID・アクセスキー・アフィリエイトID)は `rakuten_sync.js` の中に直接書き込んであるので、
GitHub Secretsに何かを登録する手間はありません。

1. この5つのファイル(フォルダ構造を保ったまま)をリポジトリにアップロードする
   - `.github/workflows/rakuten-sync.yaml` は必ず `.github/workflows/` フォルダの中に置くこと
2. GitHubの「Actions」タブ → 「楽天商品データ自動更新」→「Run workflow」を押して手動実行
3. 実行が成功したら、`products.json` に商品データ(画像・価格・リンク)が書き込まれる
4. サイト(GitHub Pages)を開いて、各お悩みカテゴリに商品が表示されているか確認

毎日21:00(UTC / 日本時間 朝6:00)にも自動実行されるので、放っておいても価格や画像は更新されます。

## 商品データを追加・差し替えたいとき

`rakuten_sync.js` の `CURATED_PRODUCTS` に、同じ形式で追記するだけです。
`itemCode` は商品ページURL(`item.rakuten.co.jp/ショップコード/商品コード/`)からそのまま作れます。

```js
{ itemCode: 'ショップコード:商品コード', name: '商品名', price: 価格, reviewAverage: 評価, reviewCount: レビュー数, affiliateUrl: 'アフィリエイトリンク', itemUrl: '商品ページURL' }
```
